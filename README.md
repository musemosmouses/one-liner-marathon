## The joke

> The ATM asked if I wanted a receipt for my disappointment.

58 characters, one line, one laugh.

## How it works

`main.ts` (Node 22, stdlib only) writes the joke — a fixed, deterministic
string — to `entry.txt` under `MAKEFUN_OUTPUT_DIR`. No clock, no randomness,
no network, no model calls: the same bytes come out on every run.
